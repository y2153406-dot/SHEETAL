How it works

Your phone obtains GPS coordinates and sends the latest location to the Guardian SHIELD server.

The map marker automatically moves whenever a new GPS position is received.

Backend updates are limited to one request every five seconds to keep the tracking system stable.

This prototype currently uses browser GPS. Hardware and background mobile tracking can be connected later.
